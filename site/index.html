Browser preview

Make scientific graphs from your own data.

Graph Builder lets you import a spreadsheet or CSV, explore your data, and export graphs. This early web version is ready for friends to try before the Windows app is packaged.

Launch Graph Builder Report a problem

A quick way to try it

  • Open the app and explore the included example data.
  • Import a CSV or Excel file, then drag columns onto the graph axes.
  • Try a plot layer, save a project, and download a graph image.

Imported data and recovery copies stay in your browser. Download an embedded project file if you want a reliable backup. This preview works best on a desktop or laptop browser.
