Scientific graphing for browser and Windows

Turn your data into clear scientific graphs.

Explore Graph Builder

Explore data, build layered scientific graphs, and save figures or reusable projects. Start with the synthetic example or import your own data. Graph Builder runs in a desktop browser and as a Windows app.

Launch Graph Builder Download Windows installer Read the user guide

The Windows app adds offline use after installation, opening project files directly from File Explorer, recent projects, update checks, and more keyboard shortcuts for opening and saving work.

View the GitHub repository or report a problem.

What you can do

  • Assign columns to axes, color, grouping, size, and other graph roles.
  • Combine points, lines, bars, box plots, fitted trends, and statistical summaries.
  • Inspect and edit rows, apply filters, calculate columns, and add reference marks.
  • Keep multiple graphs in one project, undo changes, and export PNG or SVG images.

Engineering overview

  • Inputs: CSV, TSV, TXT, XLSX, and XLS, with worksheet selection for Excel files.
  • Outputs: PNG and SVG figures, plotted-data CSV, and portable .graphbuilder projects.
  • Stack: React and TypeScript with Plotly graphs; Tauri packages the Windows app.
  • Data handling: rows are processed locally. A browser workflow with 5,000 rows and 50,000 cells has been tested; speed depends on the computer and graph.

A quick way to try it

  • Explore the included example data.
  • Import a CSV or Excel file, then drag columns onto the graph axes.
  • Try a plot layer, save a project, and download a graph image.

Imported data and recovery copies stay in your browser. Download an embedded project file for a reliable backup. The browser app works best on a desktop or laptop.
