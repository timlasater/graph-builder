# Project agent policy

- Work on each roadmap phase in its dedicated side branch.
- Before handing off a completed phase, run the relevant tests and build checks, commit the phase changes, and push that side branch to `origin`.
- Keep unrelated user changes out of the phase commit. If the working tree contains unrelated changes, preserve them and call them out before committing.
- The user is not a software developer. Explain technical terms in plain language when they are used, and briefly define unfamiliar concepts instead of assuming engineering background.
