# Graph Builder v0.1.4 practical review checklist

Use the updated desktop app. Mark each item Pass, Fail, or Not run. Use synthetic or non-sensitive files.

## Import and data table

- [ ] Open an Excel workbook with multiple worksheets. The worksheet names are readable.
- [ ] Import a CSV or Excel file with notes above the real header. Set **Rows to skip before header** to the number of leading rows. Confirm the header preview and verify the imported column names and row count.
- [ ] Open **View data table**. Rows have **Include in graph** checkboxes. Uncheck one row and confirm it disappears from graph calculations; check it again and confirm it returns.
- [ ] Click the yellow data-warning count. The data table opens with the Quality details visible.
- [ ] Create a graph with too few observations for SD, SE, or another statistic. Confirm the warning can be dismissed.

## Graphs, history, and shortcuts

- [ ] Click the suggested-layer button. Its information message fades away after a few seconds.
- [ ] Press **Ctrl+D**. The data table opens. Close it with Escape.
- [ ] Press **Ctrl+N**. A new empty graph appears in the current project.
- [ ] Make a graph change, then press the mouse Back button. The change is undone. Press the mouse Forward button. The change is redone.
- [ ] Import or edit a project, click **Reset example**, and accept the confirmation. Press Ctrl+Z to restore the previous project and Ctrl+Y to reset it again.

## Projects and linked sources

- [ ] Save an embedded project and reopen it. Its data and graph settings are retained.
- [ ] Save a linked project when the source file was opened by dragging it from File Explorer. The project save flow should record the source path.
- [ ] Reopen that linked project while the source file is still present. It should reconnect automatically.
- [ ] Move or rename the source file, then reopen the linked project. The reconnect prompt should show **Last found at** with the saved path.
- [ ] Test an older linked project with no saved source path using the copy prepared below. When opening it, the app should ask for the original data file and show that its folder path was not saved. Choose the original file, then save the project as linked. The saved copy should contain the source path.
- [ ] Make edits before opening another project. Confirm the save dialog offers **Discard edits and open**.
- [ ] Open another project without changes. Confirm there is no unnecessary save prompt.

To prepare the older linked project for that check:

1. In the Windows app, import a small CSV or Excel file and save a **Linked — reconnect source** project. Keep the original data file in place.
2. In File Explorer, make a copy of the `.graphbuilder` project file and give the copy a name such as `older-linked-no-path.graphbuilder`. Leave the original untouched.
3. Right-click the copy, choose **Open with → Notepad**, and find the `"source"` section inside `"data"`. Delete only the line containing `"nativePath"`. If the line immediately before it ends in a comma, remove that comma too. Keep `"mode": "linked"`, `"fileName"`, `"signature"`, and the rest of the file unchanged. Save the copy in Notepad.
4. Open the copy in Graph Builder. **Last found at** should show the data file name followed by **(folder path was not saved with this project)**. Choose the original data file to reconnect it. Save as linked under a new project file name, then open that new file in Notepad and confirm its `"data" → "source"` section now has `"nativePath"`.

## Desktop workflow

- [ ] Press Ctrl+S on a project already saved as a `.graphbuilder` file. It updates that file without opening Save As.
- [ ] Press Ctrl+Shift+S. It opens Save As and preserves the new file association after saving.
- [ ] Drag a `.graphbuilder` file from File Explorer onto the app. It opens through the normal save-or-discard flow.
- [ ] Use **Projects & export** to confirm Embedded/Linked status, matching default data mode, and **Clear recent projects**.
- [ ] Press `?` and confirm the shortcut list includes Ctrl+D, Ctrl+N, Ctrl+Z/Ctrl+Y, and mouse Back/Forward.
