# v0.2.0 feature preview

These features are on the `v0.2.0` branch. The published browser app and 0.1.4 Windows installer do not include them yet. To try the branch locally, run `npm ci` and `npm run dev` from the project folder, then open the address shown in the terminal.

## Paired plots and comparisons

Import [`examples/paired-study.csv`](../examples/paired-study.csv). Assign **Visit** to X and **Response** to Y. Add a **Paired plot** layer and select **Subject** as **Subject ID**. Each subject should have a line from Before to After. The lines do not represent an average or a statistical test.

Open **Properties → Compare groups** and add a comparison between Before and After. Choose **Paired t test** and **Subject** to match the two observations from each subject. The graph and results panel should show the mean After-minus-Before difference, its confidence interval, the p value, and the number of matched subjects. The independent Welch test is also available for measurements from separate groups. Filters and excluded rows change the calculations. Only one category pair is tested at a time; there is no correction for running several tests.

## Nonlinear curves

Import [`examples/dose-response.csv`](../examples/dose-response.csv), assign **Dose** to X and **Response** to Y, then add **Curve fit**. Choose **Dose–response (4 parameters)** for positive dose values or **Exponential decay** for a decreasing response over X. Keep a **Points** layer to see source observations. **Properties → Layers** displays the model parameters, approximate 95% confidence intervals, R², and a residual plot. A residual is the observed value minus the curve's predicted value. The model may fail or its confidence intervals may be unavailable when the data do not support a reliable fit; the app shows a message in that case.

## Figure page

Create or duplicate several graphs in one project. Open **Projects & export → Figure layout → Open layout**. Select up to four graphs, move them into order with ↑, then set the page title, columns, width, and height. Export the combined PNG. The arrangement is stored in the `.graphbuilder` project file, and the page is rendered from the current graph settings and visible data when exported. A single graph can still be exported separately as PNG or SVG.
